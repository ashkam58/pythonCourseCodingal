# Python Course Codingal

This repository contains Python programming activities and After Class Projects (ACPs) organized by Module and Lesson.

## Repository Structure

- **Module1/**: Python Basics, Data Types, Operators, Conditionals, Loops, Patterns, Functions, and Turtle Graphics (`M1L1A1.py` ... `M1L8ACP.py`)
- **Module2/**: Nested Conditional Statements, Loops, While Loops, Nested Loops, Patterns, Turtle Graphics, and Capstone Projects (`M2L1A1.py` ... `M2L8ACP.py`)
- **Module4/**: Functions, Arguments, Keywords, Exception Handling, Random & Math Modules, Lists, Tuples, Dictionaries, and Capstones (`M4L1A1.py` ... `M4L8ACP.py`)

## File Naming Format

- `M<Module>L<Lesson>A<Activity>.py` for classroom activities (e.g., `M1L2A1.py`, `M2L1A1.py`, `M4L1A1.py`)
- `M<Module>L<Lesson>ACP.py` for After Class Projects (e.g., `M1L2ACP.py`, `M2L1ACP.py`, `M4L1ACP.py`)
