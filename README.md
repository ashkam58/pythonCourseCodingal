# Python Course Codingal

This repository contains Python programming activities and After Class Projects (ACPs) organized by Module and Lesson according to the official Codingal curriculum.

## Repository Structure

- **Module1/ - Python Basics** (Lessons 1–8: `M1L1A1.py` ... `M1L8ACP.py`)
- **Module2/ - Control Flow & Turtle Graphics** (Lessons 1–8: `M2L1A1.py` ... `M2L8ACP.py`)
- **Module3/ - Python Functions and Modules**:
  - `M3L1`: Function (`M3L1A1.py` ... `M3L1ACP.py`)
  - `M3L2`: Arguments (`M3L2A1.py` ... `M3L2ACP.py`)
  - `M3L3`: Keywords (`M3L3A1.py` ... `M3L3ACP.py`)
  - `M3L4`: Exception Handling (`M3L4A1.py` ... `M3L4ACP.py`)
  - `M3L5`: Random and math module (`M3L5A1.py` ... `M3L5ACP.py`)
  - `M3L6`: Date, time, and calendar module (`M3L6A1.py` ... `M3L6ACP.py`)
- **Module4/ - Data Structures in Python**:
  - `M4L1`: Getting Started with Lists (`M4L1A1.py` ... `M4L1ACP.py`)
  - `M4L2`: Tuples (`M4L2A1.py` ... `M4L2ACP.py`)
  - `M4L3`: All About Dictionary (`M4L3A1.py` ... `M4L3ACP.py`)
  - `M4L4`: Sets and Arrays (`M4L4A1.py` ... `M4L4ACP.py`)
  - `M4L5`: Advanced Python Functions (`M4L5A1.py` ... `M4L5ACP.py`)
  - `M4L6`: Python Challenges (`M4L6A1.py` ... `M4L6ACP.py`)

## File Naming Format

- `M<Module>L<Lesson>A<Activity>.py` for classroom activities (e.g., `M3L1A1.py`, `M4L4A1.py`)
- `M<Module>L<Lesson>ACP.py` for After Class Projects (e.g., `M3L1ACP.py`, `M4L4ACP.py`)
