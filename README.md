# Python Course Codingal

This repository contains Python programming activities and After Class Projects (ACPs) organized by Module and Lesson according to the official Codingal curriculum.

## Repository Structure

- **Module1/ - Python Basics** (Lessons 1–8: `M1L1A1.py` ... `M1L8ACP.py`)
- **Module2/ - Control Flow & Turtle Graphics** (Lessons 1–8: `M2L1A1.py` ... `M2L8ACP.py`)
- **Module3/ - Python Functions and Modules**:
  - `M3L1`: Function (`M3L1A1.py` ... `M3L1ACP.py`)
  - `M3L2`: Arguments (`M3L2A1.py` ... `M3L2ACP.py`)
  - `M3L3`: Keywords (`M3L3A1.py` ... `M3L3ACP.py`)
  - `M3L4`: Exception Handling (`M3L4A1.py` ... `M3L4ACP.py`)
  - `M3L5`: Random and math module (`M3L5A1.py` ... `M3L5ACP.py`)
  - `M3L6`: Date, time, and calendar module (`M3L6A1.py` ... `M3L6ACP.py`)
- **Module4/ - Data Structures in Python**:
  - `M4L1`: Getting Started with Lists (`M4L1A1.py` ... `M4L1ACP.py`)
  - `M4L2`: Tuples (`M4L2A1.py` ... `M4L2ACP.py`)
  - `M4L3`: All About Dictionary (`M4L3A1.py` ... `M4L3ACP.py`)
  - `M4L4`: Sets and Arrays (`M4L4A1.py` ... `M4L4ACP.py`)
  - `M4L5`: Advanced Python Functions (`M4L5A1.py` ... `M4L5ACP.py`)
  - `M4L6`: Python Challenges (`M4L6A1.py` ... `M4L6ACP.py`)
- **Module5/ - Object-Oriented Programming**:
  - `M5L1`: Object-Oriented Programming (`M5L1A1.py` ... `M5L1ACP.py`)
  - `M5L2`: More on Object-Oriented Programming (`M5L2A1.py` ... `M5L2ACP.py`)
  - `M5L3`: Inheritance (`M5L3A1.py` ... `M5L3ACP.py`)
  - `M5L4`: Encapsulation and Special Functions (`M5L4A1.py` ... `M5L4ACP.py`)
  - `M5L5`: Abstraction and Polymorphism (`M5L5A1.py` ... `M5L5ACP.py`)
- **Module6/ - Pygame & Game Development**:
  - `M6L1`: Let’s Begin with Pygame (`M6L1A1.py` ... `M6L1ACP.py`)

  - `M7L1`: Widgets for Starters! (`M7L1A1.py`, `M7L1A2.py`, `M7L1ACP.py`)
  - `M7L2`: Tkinter Geometry Managers (`M7L2A1.py`, `M7L2A2.py`, `M7L2ACP.py`)
  - `M7L3`: Where’s the Event? (`M7L3A1.py`, `M7L3A2.py`, `M7L3ACP.py`)
- **Prompt Engineering/ - Generative AI & Game Lab Track**:
  - `Lesson 1`: Meet the World of Prompts (Chatbot exploration & prompt detectives)
  - `Lesson 2`: Clear Prompts, Clear Code (Button Builder & Click-to-Color Circle)
  - `Lesson 3`: Animations with Prompts (Rocket Builder, Penguin Jumper, Cat Chaser, Bouncing Ball)
  - `Lesson 4`: Storytelling with Prompts (Space Rescue Story with branching riddles & Sea Rescue Adventure)
  - `Lesson 5`: Game Building with Prompts (Star Catcher with HUD & Fruit Basket Dash)
  - `Lesson 6`: Prompt-to-Project Showcase (Capstone: Choose Your Own Game & Choice Board)

## File Naming Format

- `M<Module>L<Lesson>A<Activity>.py` for classroom activities (e.g., `M3L1A1.py`, `M4L4A1.py`, `M6L5A1.py`)
