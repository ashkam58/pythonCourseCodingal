### Grandmaster AI Quiz Key & Concept Review

* **What is a prompt?**  
  *Answer*: A text instruction or question provided to an AI model to guide its output.
* **Key elements of an effective prompt**:  
  *Answer*: Specificity, clear role/persona, explicit output constraints (length, format), and context.
* **Zero-Shot vs. Few-Shot Prompting**:  
  *Answer*: 
  - *Zero-shot*: Asking the model to perform a task with zero examples.
  - *Few-shot*: Providing 1–3 solved examples before asking the query.
* **System Prompt vs. User Prompt**:  
  *Answer*: 
  - *System prompt*: Sets the background behavior, rules, boundaries, and persona.
  - *User prompt*: The dynamic message or question submitted by the user.
* **Temperature parameter in LLMs**:  
  *Answer*: Controls randomness/creativity. Lower values (e.g. 0.0–0.2) = focused, deterministic answers; Higher values (e.g. 0.7–1.0) = diverse, creative answers.
* **Game Lab / Code.org Core Mechanisms**:  
  - *Draw Loop*: `function draw()` executes repeatedly (~30 times/sec) to render frames.
  - *Velocity Reversal (Bouncing)*: When a sprite reaches the boundary, multiply its velocity by `-1` (e.g., `ball.velocityX = -ball.velocityX`).
  - *Gravity Simulation*: Add a constant positive value to `velocityY` every frame (`sprite.velocityY += gravity`).
  - *Collision Detection*: Using `sprite.isTouching(target)` or `sprite.bounce(obstacle)`.

### Coding Grade 9-12 Quiz Key & Concept Review

* **Data Types**: `int`, `float`, `str`, `bool`. Remember: `type(3.14)` returns `<class 'float'>`.
* **String Slicing**: `str[start:stop:step]`. Negative index `-1` represents the last character. `s[::-1]` reverses a string.
* **Operators**: `//` is floor division (e.g., `7 // 2 == 3`), `%` is modulo (remainder), `**` is exponentiation.
* **Loops**:
  - `break`: Immediately exits the loop.
  - `continue`: Skips the rest of the current iteration and jumps to the next iteration.
  - `pass`: A null operation / placeholder statement.
* **Functions**:
  - Defined with `def`.
  - Arguments without default values must come before arguments with defaults.
  - `*args`: Collects positional arguments into a `tuple`.
  - `**kwargs`: Collects keyword arguments into a `dict`.
* **Exception Handling**:
  - `try`: Code that may raise an error.
  - `except ErrorType`: Catches and handles the error.
  - `else`: Executes if no exception occurred.
  - `finally`: Always runs regardless of whether an error occurred.
* **Data Structures**:
  - *List*: Ordered, mutable, allows duplicates: `[1, 2, 3]`.
  - *Tuple*: Ordered, immutable, allows duplicates: `(1, 2, 3)`.
  - *Dictionary*: Key-value pairs, unordered/insertion-ordered, keys must be immutable: `{"a": 1}`.
  - *Set*: Unordered, mutable, unique elements only: `{1, 2, 3}`.
* **OOP Core Pillars**:
  - *Encapsulation*: Bundling data and methods; hiding internal state using private variables (`__var`).
  - *Inheritance*: Deriving child classes from a parent class (`class Child(Parent):`).
  - *Polymorphism*: Using a unified interface with different underlying forms (e.g., method overriding).
  - *Abstraction*: Hiding complex implementation details using abstract base classes (`from abc import ABC, abstractmethod`).
* **Pygame**:
  - `pygame.init()` must be called first.
  - Frame rate cap: `clock.tick(60)`.
  - Always handle `pygame.QUIT` in the event loop to allow closing cleanly.
* **Tkinter**:
  - `root = tk.Tk()` creates the main window.
  - Geometry managers cannot be mixed within the same container (`pack()` and `grid()` shouldn't be called on siblings in the same master frame).
  - `root.mainloop()` starts the event listener loop.

### 🧠 Module 7 Quiz Submission Quick Reference

1. **Lesson 1 - Introduction to Python**:
   - `print()` displays text or numbers to the console.
   - `#` is used for single-line comments; triple quotes `'''` for multiline strings/comments.
   - Python keywords cannot be used as variable names (e.g., `import keyword; keyword.kwlist`).
2. **Lesson 2 - Operators and Data Types**:
   - Four core data types: `str` (string), `int` (integer), `float` (floating-point number), `bool` (boolean).
   - Division operators: `/` returns float (e.g. `5 / 2 = 2.5`), `//` returns integer floor (e.g. `5 // 2 = 2`), `%` returns remainder.
   - Swapping two variables: `a, b = b, a`.
3. **Lesson 3 - Conditional Statements and Date Time**:
   - `if`, `elif`, `else` execute conditional branches based on boolean logic.
   - Indentation is required in Python (blocks inside `if` statements must be indented).
   - `import datetime; datetime.datetime.now()` provides the current date and time.
4. **Lesson 4 - Loops**:
   - `for i in range(1, 11):` loops through numbers 1 to 10.
   - `while` loops execute repeatedly while a condition is True.
   - An Armstrong number equals the sum of its own digits each raised to the power of the number of digits (e.g., 153, 370, 371, 407).
5. **Lesson 5 - Functions**:
   - Defined using `def function_name(param):`.
   - `return` exits the function and produces an output value.
   - Recursion is a function calling itself; requires a base case to terminate (e.g., factorial, Fibonacci).
6. **Lesson 6 - Introduction to Turtle**:
   - Setup: `import turtle; screen = turtle.Screen(); t = turtle.Turtle()`.
   - Drawing: `forward(px)`, `backward(px)`, `right(deg)`, `left(deg)`.
   - Coloring: `color("color")`, `begin_fill()`, `end_fill()`.
   - Prevent window exit: `turtle.done()`.
