## 🧠 Quiz Answer Key & Key Concepts Guide

Below are the core answers and concepts for the 6 lessons in **Quiz Submission**:

### Lesson 1: Introduction to Python
* **What is Python?**: An interpreted, high-level, dynamically typed general-purpose programming language.
* **Comments in Python**: Created with `#` (single-line) or triple quotes `'''` / `"""` (multiline). Comments are ignored by the Python interpreter.
* **Keywords**: Reserved words that cannot be used as variable names (checked using `keyword.kwlist`).

### Lesson 2: Operators and Data Types
* **Four Fundamental Data Types**: `int` (integers), `float` (decimals), `str` (text strings), `bool` (`True` or `False`).
* **Arithmetic Operators**: `+`, `-`, `*`, `/` (normal division), `//` (floor division), `%` (modulus/remainder), `**` (exponentiation).
* **Comparison Operators**: `==` (equal to), `!=` (not equal to), `<`, `>`, `<=`, `>=`.
* **Value Swapping in Python**: Can be done cleanly in one line: `a, b = b, a`.

### Lesson 3: Conditional Statements and Date Time Module
* **Decision Making**: `if`, `elif`, `else` determine execution flow based on boolean conditions.
* **Indentation**: Python uses 4 spaces (or a tab) to define code blocks instead of curly braces `{}`.
* **`datetime` Module**: `datetime.datetime.now()` retrieves the current system date and time.
* **`calendar` Module**: `calendar.calendar(year)` prints the entire 12-month calendar for that year.

### Lesson 4: Loops
* **`for` loop**: Used when the number of iterations is known in advance; often paired with `range(start, stop, step)`.
* **`while` loop**: Runs as long as a condition evaluates to `True`. Requires manual loop variable increments.
* **Prime Number Logic**: A number greater than 1 that is divisible only by 1 and itself. Can be tested efficiently up to `int(n ** 0.5) + 1`.
* **Armstrong Number**: An integer whose sum of digits raised to the power of the number of digits equals the integer itself (e.g., $153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153$).

### Lesson 5: Functions
* **Function Definition**: Declared using the `def` keyword followed by the function name, parameters in parentheses, and a colon `:`.
* **Return Statement**: `return` exits a function and sends a result back to the caller.
* **Recursion**: A programming technique where a function calls itself to solve a smaller instance of the same problem.
* **Base Case**: The stopping condition in recursion that prevents an infinite loop and stack overflow.

### Lesson 6: Introduction to Turtle
* **Canvas Setup**: `turtle.Screen()`, `screen.bgcolor("black")`, `screen.title(...)`.
* **Turtle Pen**: `t = turtle.Turtle()`, `t.speed("fastest")`, `t.pensize(2)`.
* **Movement**: `t.forward(dist)`, `t.backward(dist)`, `t.right(angle)`, `t.left(angle)`.
* **Pen Control**: `t.penup()`, `t.pendown()`, `t.goto(x, y)`.
* **Filling Shapes**: `t.begin_fill()`, draw geometry, `t.end_fill()`.
* **Keeping Window Open**: `turtle.done()` prevents the canvas window from closing immediately after the script finishes.
